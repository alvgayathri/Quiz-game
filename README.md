# Quiz Game in C

## Description
This is a simple command-line Quiz Game written in C. The game presents multiple-choice questions to the user, evaluates the answers, and keeps track of the score. The final score is stored in a file named `quiz_scores.txt`.

## Features
- Displays multiple-choice questions
- User selects an answer (A, B, C, or D)
- Instant feedback on correct/incorrect answers
- Stores the final score in a text file


## Sample Questions
- What is the capital of France?
- Which programming language is known as the 'mother of all languages'?
